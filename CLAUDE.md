# coopTracker — правила для Claude

Перед работой прочитай [DESIGN.md](DESIGN.md): там все решения и открытые вопросы. Не принимай заново то, что уже решено; если решение меняется — обнови DESIGN.md.

- Работаем подшагами из раздела «Порядок работы» в DESIGN.md. После каждого подшага — остановка и короткий отчёт пользователю.
- Новые зависимости — только после обсуждения с пользователем: что даёт, чем платим, какие альтернативы.
- `packages/graph-core` — чистый TypeScript без зависимостей в рантайме и без I/O. Сеть, БД, DOM, текущее время и случайность передаются параметрами. Функции не мутируют входные данные.
- У каждого правила графа (инвариант, вычисление состояния, слияние) есть тест. `npm test` и `npm run typecheck` должны быть зелёными до коммита.
- Ошибки возвращаются кодами, а не текстом: тексты живут в переводах интерфейса (русский и английский).
- Коммиты — только после «ок» пользователя. Без строки `Co-Authored-By: Claude` и без любого упоминания Claude как соавтора.
- Никакой игровой терминологии в продукте: редакторы квестов — только референс визуального стиля.

## Команды

- `npm test` — все тесты
- `npm run test:watch` — тесты в режиме наблюдения
- `npm run typecheck` — проверка типов во всех пакетах
- `npm run format` — форматирование Prettier
